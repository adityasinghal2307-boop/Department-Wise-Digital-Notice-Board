# 🎓 Department Wise Digital Notice Board

**Live Demo:** https://department-notice-board.onrender.com

## 📌 Project Overview

Department Wise Digital Notice Board is a web-based application designed to provide a digital platform for displaying and managing college notices department-wise.

It helps students and faculty access important academic announcements in one place.

## 🎯 Objectives
- To digitize the traditional college notice board.
- To provide easy access to department-wise notices.
- To make notice information accessible online.
- To improve communication between students and faculty.

## 🛠️ Technologies Used
- React.js
- JavaScript
- Vite
- HTML
- CSS

## 💻 Run Project Locally

1. Clone this repository:

   `git clone https://github.com/adityasinghal2307-boop/Department-Wise-Digital-Notice-Board.git`

2. Open the project folder:

   `cd Department-Wise-Digital-Notice-Board`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`
